How to edit the map

Open maps/world.map. Each grid cell is a 7×7 bay. Repeating a room number joins those bays into one room; use connected cells to make larger or L-shaped rooms.

Internal door lines use room IDs: door 01 05 3 connects Rooms 01 and 05, three map units along their shared wall. The offset starts at the west end of a horizontal wall or the north end of a vertical wall. Remove a line to close that doorway. If rooms share multiple separate wall segments, the door uses the first segment found scanning from the northwest.

exit east 07 places an outside door on the east exterior wall of room 07, centered along that room's boundary. Add an optional wall offset, such as exit east 09 20, to align linked building exits; offsets count map units from the west edge for north/south walls or the north edge for east/west walls. The connections section links exits and paths.

magicdoor north 04 A-B links a room-side portal to the other door with the same pair ID. Each door is centered on the named room's exterior wall.

Object lines are box col row x y width depth height credits, table col row x y width depth height credits, cat col row x y scale credits, or guitar|h|snake|apple|telephone|glasses|toycar|dog|penny|fish col row x y scale credits. Drop a paired object in a room containing its matching picture to earn credits; the object stays on display. Picking it up again reverses the credit and clears the pairing. A wall picture is picture box|cat|dog|guitar|coffee-table|h|snake|apple|telephone|glasses|penny|fish col row side offset bottom-z width height. Its side is north, east, south, or west; offset runs from the west edge on north/south walls or the north edge on east/west walls. For floor objects, x and y are map units within the bay.
